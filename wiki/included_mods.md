# Included Mods

Farming Experience includes a carefully selected set of mods designed to keep the game close to its original and nostalgic feel, while making it more enjoyable and immersive for all players.

::: tip Note
Pre-installed mods differ slightly between the CurseForge and Modrinth versions of Farming Experience due to mod availability on each platform. You can add more mods yourself, but make sure they're compatible with the modpack's mod loader and Minecraft version.
:::
